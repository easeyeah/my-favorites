## 使用规则

- 安全边距：图标四周留出不少于图形高度 1/4 的空白。
- 最小使用：图标不小于 16 px；横排主标不小于 96 px 高。
- 卡片保持左下→右上的阶梯关系，不调换顺序。
- 禁止：拉伸变形、换主色、加渐变 / 阴影 / 描边、在杂乱背景上直接放白底版。

## 说明

- SVG 图形 2026-11-19 起为**干净矢量重绘**（初版位图描摹有锯齿且色值偏暗，已弃用）：造型、阶梯与折角关系与原位图一致，色值校准至上方色板；`svg/` 目录为唯一权威母版，管理台/扩展引用的副本以 `apps/web/public/brand/` 与 `apps/extension/public/icon/` 为准。
- 横排主标 `lockup.png` 含文字，文字部分未矢量化；正式使用时建议用设计工具排字，或直接引用位图。
- 本规范为草案，色值与圆角在进入界面开发后可再校准。
