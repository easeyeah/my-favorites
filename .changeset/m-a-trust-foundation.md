M-A 可信基础：隐私策略链路、身份映射与持久重试、整理事务化、安全默认值

- 隐私：五动作策略引擎（读取/上传/模型/抓取/快照）——扩展端捕获前/上传前/快照前前置校验，规则未加载保守降级仅元数据；服务端对正文/抓取/快照/摘要入口独立纵深校验；抓取网络访问策略（禁私网/回环/链路本地，DNS 解析与每跳重定向后校验，自建可显式放行）；规则变更自动清理存量正文与快照；日志脱敏
- 收件箱（A2）：持久设备 ID + device_id+browser_bookmark_id↔app_bookmark_id 映射（/inbox/map 幂等）；扩展持久待发送队列（SW 重启可恢复、离线保留）；镜像模式（D20）——应用库归位后浏览器节点同步移动（/browser/ops 拉取-执行-回执），mirrorGuard 防监听循环
- 整理（A3）：有序带版本号数据库迁移（迁移前 VACUUM INTO 一致性备份，WAL 安全）；提案保存稳定 ID+原始状态+修订版本；apply 单事务（异常整体回滚）；冲突检测（提案后手改跳过并报告，不静默覆盖；回滚遇后续修改跳过）；合并改软归档（正文/快照/私密属性保留，回滚可恢复）
- 安全（A4）：非开发部署首启强制设置管理员凭据（503 门槛 + 一次性 setup）；登录速率限制；令牌列表/撤销/logout；Provider Key AES-256-GCM 加密落库（MF_SECRET_KEY，生产强制）；快照上传 MHTML 格式校验与 20MB 上限；快照净化查看器（禁脚本/表单/外链 + CSP）与受控下载；captureMHTML base64 解码修复
- 修复：Dockerfile prod 目标补 web-dist 构建；E2E 用例环境自洽（自带 server + MF_ENV）
