D66 补充 · MCP 接入页补鉴权说明（2026-11-21）：用户问「MCP 接入不需要提供 apikey 吗」。回答与落地：**MCP 无独立 API Key——与管理台登录同源（Bearer 令牌，D24 摘要化存储/可撤销）**，三种部署场景同源覆盖（ADMIN_PASSWORD env / 生产首启设置后 DB hash / dev 无密码）。设置→MCP 接入新增「鉴权」说明块（已登录：示例直接包含当前登录令牌，复制即用含保管提醒；未登录：指路「连接与安全」登录签发 + 占位符替换；未设密码纯内网：无需鉴权 + 公网务必设密码提醒）。「复制接入配置示例」令牌感知——已登录时带真实令牌免手工替换。
