## 2. 关键工程决策（含对技术方案的偏离）

| 决策 | 理由 |
|---|---|
| **数据层 node:sqlite 替代 Drizzle+libsql** | 零原生依赖：不破坏 85KB bundle 交付、容器免编译工具链、ARM64 天然支持；迁移脚本化（CREATE IF NOT EXISTS）。Drizzle 推迟到云端 Postgres 阶段 |
| **合并重复 = 同域同名相似检测**（技术方案原为 canonical 分组） | url_canonical 有 UNIQUE 约束（入库即查重），canonical 相同的记录**不可能**在库内共存——推导出库内重复只可能是同域同名近重复。这是设计审查发现的原方案逻辑缺陷 |
| **收件箱流水线规则+LLM 双轮合一版本** | 规则移动与 LLM 移动合并写单个 organize_version，一次回滚全部还原 |
| 容器基镜像 node:22→**node:24-alpine** | node:sqlite 在 24 稳定可用，无需实验 flag |
| 公开导航站搜索落地页挂根路径 | review 发现 `/s/*` 定义在带 `/api/v1` 前缀的子应用上会 404——公开页必须挂根 |
| 扩展 M1 固定 host_permissions localhost:3000 | 云端/NAS 自定义 origin 用 optional_host_permissions（M2） |

## 5. 如何运行与人工检查指引

```bash
# 1. 启动服务端（Docker）
docker compose -f docker/docker-compose.dev.yml up -d
# 2. 构建扩展
pnpm --filter @mf/extension build
# 3. Edge/Chrome 加载：开发者模式 → 加载解压缩 → 选 apps/extension/.output/chrome-mv3
# 4. 扩展 popup → 设置 → 测试连接 → 创建收件箱
# 5. 任意网页右键"收藏到 my-favorites"，或 popup 丢进收件箱观察自动归位
# 6. 打开新标签页即为导航站；侧栏"聊天整理"输入"整理"走 diff 流程
```
