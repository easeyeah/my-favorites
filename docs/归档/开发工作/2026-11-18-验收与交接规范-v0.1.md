# 验收与交接规范（v0.1）

> 日期：2026-11-18；适用 DEV-01～DEV-26。本文定义未来验收要求，**不是已通过的测试报告**。

## 1. 状态与证据分级

每个任务使用以下状态，不用一个“完成”代替全部阶段：

| 状态 | 含义 | 必备证据 |
|---|---|---|
| 待领取 | 本轮清单初始状态 | 任务 ID、负责人待定 |
| 已复现/设计确认 | 缺陷可重现或新增能力设计批准 | 输入、环境、实际/预期、测试/设计链接 |
| 实现中 | 已开发但未完整验收 | PR、范围、未完成项 |
| 自动化通过 | 对应层级回归通过 | 命令、提交、结果、制品 |
| 真实环境通过 | 真 Chrome/Edge/Docker/NAS 验证 | 版本、操作步骤、截图/记录 |
| 已验收 | 验收条件完整满足、文档同步 | 审核人、证据、限制和交接 |
| 阻塞/降级 | 未满足条件 | 原因、风险、禁用范围、后续任务 |

- 静态看到代码缺少校验 ≠ 已证明生产数据泄露；mock LLM 分类通过 ≠ 真实模型质量达标。
- Chromium 自动化通过 ≠ Chrome 与 Edge 均真实通过；ARM64 模拟器通过 ≠ ARM64 NAS 实机通过。
- 生产资源必须有峰值负载数据；打印 `docker stats` 字符串不等于门禁。
- 未跑、skip、占位断言均列 pending；不能从统计中隐藏后宣布全过。

## 2. 测试环境约定

### 2.1 测试层级

| 层级 | 环境 | 用途 |
|---|---|---|
| 单元 | 宿主机 Vitest | URL、隐私判定、schema、diff、状态机纯逻辑 |
| API 集成 | Docker server + 独立 SQLite volume + mock 站点/模型 | 认证、对象权限、事务/幂等、网络限制、持久任务 |
| 生产语义 E2E | prod Docker、真实 setup/ADMIN_PASSWORD 两模式 + Playwright | 不能默认 MF_ENV=test 跳过认证 |
| 扩展运行时 | 打包产物 + Chrome/Edge 独立 profile | 权限、activeTab、capture、SW 终止、alarms、浏览器节点移动 |
| 镜像/恢复/负载 | prod amd64/arm64、隔离数据目录 | 升级/回退、非 root、资源、恢复 |
| 真实模型质量 | 固定脱敏样本、用户明确配置模型 | 规则/内容比较、用量和质量，不进入必须消耗费用的普通 CI |

服务端遵循仓库 Docker 优先要求。当前 E2E fixture 启动宿主 node 的方式是 DEV-25 的整改对象，不作为新任务的推荐验收方式。

### 2.2 数据集

- 复用 `packages/shared/src/eval-samples.ts`，不重复建设第二套没有用途的样本库。
- 增补规模种子：100、1000、10001 条书签；搜索压力可另加 50000 条。
- 必含：同名不同父目录、空目录、多级目录、中文/英文/无标题、hash 路由、签名参数、隐私/私密/软归档、正文失败、多版本快照。
- 故障站/模型由本地 Docker 提供：慢响应、超限、畸形 JSON、重复结果、redirect、DNS 暂态、登录页。
- 禁止使用真实银行、云元数据、用户登录态和第三方私密正文完成安全测试。真实个人数据恢复演练保存在个人环境，报告只留脱敏计数/hash。

### 3.3 五条用户任务链

1. **收藏**：未配 AI → 收藏普通页 → 明确书签成功/内容状态 → 重复可解释 → 失败可恢复 → 离线排队不串实例。
2. **找回**：目录/标题/原 URL/备注/正文 → 命中片段 → 正确原页 → 已失效项可查私有快照；无模型基础搜索可用。
3. **整理**：选范围 → 看实际处理总数 → diff 逐项接受 → 展示冲突 → 应用 → 刷新后历史 → 撤销 → 浏览器镜像结果可理解。
4. **快照**：真实 Chrome/Edge popup → 原生捕获 → 上传 → 重启 → 查看/下载 → 净化不外联 → 用户删除空间回收；隐私/受限页失败不假成功。
5. **备份恢复**：用户明确选择完整备份 → manifest/hash → 空实例恢复 → 凭据重设/重连 → 书签/正文/快照/版本可用 → 不重放旧设备任务。

每条均需覆盖：正常、无模型、服务端不可达、令牌撤销、重试/重启。不能只验证 API 返回 200。

## 4. 非功能验收

### 4.1 性能与资源

| 项 | 门槛/目标 | 测量规则 |
|---|---|---|
| prod 镜像 | ≤250,000,000 bytes | docker image inspect；每架构分别测，不用压缩下载体积偷换 |
| server 容器内存 | 峰值 <300,000,000 bytes | 10000 条、有界抓取/快照/搜索/备份负载，采样峰值与时长；Ollama 单列 |
| 本地导航 | 指定设备目标 300ms 内可操作 | 2000/10000 条，报告 P50/P95；冷/热缓存、离线分别测 |
| 关键词搜索 | 受控环境 P95 目标 <500ms | 1000/10000/50000 条、中文/正文；模型 query embedding 耗时单列 |
| 规则首阶段 | 沿用 <15s 目标 | 指定数据量，禁止隐藏 LIMIT；导入至预览/导航 <60s 另测 |
| 归位即时建议 | 沿用缓存命中 <50ms 目标 | 只计规则/缓存路径，网络耗时与业务耗时分开报告 |

硬红线不达标不能发布；性能目标未达标必须列瓶颈、输入规模及产品影响，由负责人明确裁剪而非悄悄放宽。

### 4.2 兼容性与运维

- Chrome 与 Edge：明确版本、OS、扩展 zip/commit、实际权限、普通/中文/登录/受限/隐私捕获矩阵。
- amd64 与 arm64：构建、启动、SQLite 迁移、恢复、信号退出、文件权限；arm64 实机缺失时保持待验收。
- Docker prod：MF_ENV 生产语义、非 root、真实 volume、只读根、无 node_modules 运行层、实际资源限制。
- Ollama：提前拉模型、断外网、摘要/整理/embedding 按用途配置；无模型时不影响基础任务。
- 发布制品与测试制品 commit 一致，附 digest/SHA256、版本兼容矩阵和已知限制。

## 5. 发布出口条件

### G0：隔离环境安全基础

- [ ] DEV-01～08 的安全与一致性条件通过；所有可达旧入口同样覆盖。
- [ ] capture 真实行为已验证；若禁用仅能作为测试阶段降级，不冒充完整快照链路通过。
- [ ] 不将未经完整备份/恢复验证的数据作为唯一副本。

### G1：可回退自用

- [ ] 导入、URL、镜像、SW 恢复、队列幂等通过。
- [ ] 完整备份到新实例恢复完成，回退手册可执行。
- [ ] 新用户可在无 AI 条件下安装与使用基础任务。

### G2：核心体验

- [ ] 五条用户任务链均有验收记录。
- [ ] 离线导航可用；资料库/搜索不要求用户接受 AI 或替换新标签页。
- [ ] 自动分类与真实模型质量证据分开；没有实测的质量/成本数字不对外承诺。

### G3：可发布自建预览版

- [ ] P0 清零，所有标记“发布门禁”的 P1/P2 完成。
- [ ] Docker、Chrome/Edge、ARM64、资源硬红线通过。
- [ ] 干净安装/升级/恢复/回退有人独立执行，证据完整。
- [ ] README/隐私说明/权限说明/known issues 与制品一致。
- [ ] 未完成能力明确默认关闭；若五条核心任务链缺失，不宣称本轮完整发布达标。
- [ ] 不以此出口声称云端 SaaS、加密私密库、完整双向同步或完整纯本地已就绪。

## 7. 本轮规划文档自身的交付范围

本轮新增评估、任务、验收规范与索引；未修改产品行为、未递增产品功能文档版本、未生成应用 changeset，因为没有功能变更。功能开发工程师须在各自落地 PR 中完成这些步骤。

历史 `2026-11-17` 总结中的部分完成判断与本轮静态发现不一致时，保留历史并在 DEV 执行记录追加复核结果；不得把历史测试数字引用为当前提交的运行验证。
