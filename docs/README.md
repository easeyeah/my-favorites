## 文档约定（D48）

1. **活文档制**：产品/技术两份文档不再带版本号，随代码**持续修改**；版本历史由 git 承担，不再每轮复制成新文件。
2. **功能变更必须回写**：合入功能时同步改《产品.md》/《技术方案.md》，决策只追加到《决策记录.md》（新决策给下一个 D 编号，不复用、不改写旧条目）。
3. **实现状态标记**（产品文档功能清单专用，让半成品不被文档包装成已交付）：
   - ✅ 已交付（代码 + 验收通过）
   - 🚧 半成品/有已知差异（见《产品.md》「已知实现差异」一节）
   - 📋 规划中（代码没有，只描述意图）
4. **代码是事实源**：端点、表、入口、环境变量以 `apps/`、`packages/` 代码为准；文档只做归纳，不发明能力。
5. 界面设计依据是 `apps/web` 代码 + `?mock` 演示模式与 [AGENTS.md](../AGENTS.md) 的「管理台 UI 设计规范」，**不是**冻结原型。
