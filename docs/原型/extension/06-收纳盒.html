✅ 本页讨论点已全部决议（2026-11-18 · D37 收口）——决议清单如下，原始提案保留供追溯
收口决议（按「最简原则」定案）
  • 入口：投递口/管理口分离（工具栏角标）；文件夹位置默认书签栏（可在原型 07 设置改）
  • 歧义阈值：80% 起步，按实际回滚率调整（D28）
  • 歧义集中询问：攒 ≥3 条触发（侧栏聊天 / popup 收纳盒页）
  • 隐私条目：支持「按域名记忆」本地规则自动归位（不走 AI，不出网）
原始提案（供追溯）
  1. 入口的技术现实（已修正 2026-11-18）：浏览器原生文件夹下拉不可定制、文件夹无法加角标——文件夹只做物理投递口，管理界面入口 = 扩展工具栏图标（角标 = 待处理数） → popup 收纳盒区；书签右键可加「立即归位 / 查看建议」菜单项（contextMenus 支持书签上下文）。遗留小问题：文件夹放书签栏（投递可见易拖，当前设计）还是收进「其他书签」下（不占栏位）？建议：书签栏。
  2. 默认模式（已定 D27）：全自动为默认——静默归位 + 版本兜底 + 轻提示可撤销；确认模式降为设置项，给不放心的人。
  3. 歧义阈值：全自动下，置信度低于多少算「歧义」而留下询问？阈值越低 AI 越敢动、询问越少。建议：80% 起步，按实际回滚率调整。
  4. 歧义上限：歧义条目攒几条后集中询问？当前在侧栏聊天里问（03 原型）；管理台是否也要一个「待确认」区块？
  5. 隐私条目交互：隐私域名条目不允许 AI 碰，只能手动选目录（当前）——是否提供「按域名记忆，下次同域名自动进 XX 目录」的本地规则（不走 AI）？
