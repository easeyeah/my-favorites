收口决议（按「最简原则」定案）
  • 收藏默认目的地：缓存未命中 → 落收纳盒异步分类，不当场弹选择（D27 哲学）
  • 快照开关：默认开（当前交付自建端，存储无配额压力；云端档再评估）
  • 备注输入：保留，收进「添加备注」折叠式入口，主路径更轻

原始提案（供追溯）
  1. 收藏默认目的地：缓存未命中时，默认「落收纳盒异步分类」（当前设计）还是「让用户当场从最近目录中选一个」？前者最省事、后者掌控感更强。
  2. 快照开关默认值：「同时保存快照」默认开（当前原型，存储换安心）还是默认关（存储保守，云端配额友好）？全局开关放设置页。
  3. popup 信息密度：当前有 AI 建议 + 快照 + 备注 + 收纳盒入口四块。是否砍掉「备注」让 popup 更轻？
  4. 变体 B 的 chip 推荐：当场展示「猜你想放」目录 chips 是否有必要？它与收纳盒自动归位功能重叠——保留会多一条路径，砍掉更聚焦。
