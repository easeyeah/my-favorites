样式精细化调参指南 下一轮：界面风格打磨就改这里

所有视觉参数集中在 _shared.css 顶部「设计令牌」区——改一处，17 屏全局生效：

  • 颜色：--text / --text-2 / --text-3（三级文字灰度）、--border(-2)（两级边框）、--primary（近黑主色）、--*-soft（浅底色）——想更有温度只动这几个
  • 密度：.card-b 与 .lrow 的 padding、.grid* 的 gap——改小 = 更紧凑的信息密度
  • 圆角：--radius（容器 10px）/ --radius-s（控件 6px）——想柔和就调大
  • 层级手感：--shadow-1/2/3（极简风格阴影很轻，层级主要靠边框深浅）
  • 字体：--font 字体栈、body font-size（15px）、.hint（13px）——可读性调这里
  • favicon 灰阶：.fc-1 ~ .fc-8 八档灰度

改完刷新即见全部效果（本地预览已启用 no-store 不缓存）。评审时如果某屏「说不出哪里丑但就是丑」，通常是密度/灰度对比问题——先调 --border 与 .lrow padding。
