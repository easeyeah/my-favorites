收口决议（按「最简原则」定案）
  • 公开站摘要两行固定；分组范围可独立微调——与 D23 显式发布集合同一机制，无需新功能
  • 模板优先级：先做极简清单（成本低）
  • 站点化严格度已定（D31）：默认严格首页 + 自定义卡例外
  • 无首页域名升级：默认开启 + 通知说明
原始提案（供追溯）
  1. 新标签页与公开站的关系（D29 已定配置各自独立）：公开站的摘要长度（两行）与分组范围是否允许独立于私有版微调？
  2. 发布内容范围：公开链接是否支持「只发布部分分组」（如只公开开发工具组，隐藏生活组）？涉及隐私细粒度控制。
  3. 模板优先级：4 套模板中，M1 之后先做哪套——极简清单（成本低）还是个人主页（对 P2 人群吸引力大）？
  4. 站点化的严格度（D30 衍生）：AI 分析默认严格首页；「自定义卡片」是唯一允许任意 URL（含深链）的手动例外。高频深链（点击 ≥N 次）要不要自动获得直达卡？建议：不自动，只弹提示引导建自定义卡。
  5. 无首页域名升级：只收藏过文章的域名自动升级为站点卡（上表 54 条）——默认开启 + 通知说明（当前设计）vs 先列清单让用户逐个确认？
